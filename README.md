### Featured Projects

**[CrisisMatch — Community Crisis & Resource Matcher](https://github.com/swapneel999/CrisisMatch)**
End-to-end applied AI pipeline that fine-tunes a localized open-source model (1.1B-parameter TinyLlama, 4-bit quantized) via QLoRA, applying LoRA to the attention modules and training entirely on a consumer-grade GPU. Took a crisis-message classifier from a 0.05 zero-shot baseline to 0.62 fine-tuned accuracy (0.67 weighted F1) with zero hallucinations and zero data leakage. Experiments tracked in MLflow; served through a FastAPI/Uvicorn backend with a React/Tailwind/Vite frontend.

`Python` `FastAPI` `React` `MLflow` `QLoRA` `Hugging Face`

**[AI Website Builder](https://github.com/swapneel999/apex-detailing-demo)**
A 5-agent AI pipeline (Claude Code subagents) automating end-to-end website production — scraping, design, backend, QA, and deployment — with strict single-writer ownership enforced across 7 interlocking JSON state files. Backed by formal JSON Schema (draft-07) contracts and a 180+ test suite run as a hard gate before any output is considered complete. Shipped production Next.js/TypeScript/Tailwind sites end-to-end, deployed to Vercel.

`Next.js` `TypeScript` `Tailwind` `Claude Code` `JSON Schema`
